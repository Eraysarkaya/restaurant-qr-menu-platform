# Ekran görüntüleri

Bu klasördeki masaüstü görüntüler yerel demo verileriyle çalışan güncel uygulamadan alınmıştır:

- `01-home.png`: restoran ana sayfası
- `02-menu-hamburgers.png`: hamburger kategorisi, arama ve görselli ürün kartları
- `04-admin-dashboard.png`: oturum açılmış yönetici genel bakış ekranı
- `05-admin-products.png`: ürün arama, durum ve hızlı işlem ekranı
- `06-platform-dashboard.png`: geliştirici paneli restoran kurulumları ekranı
- `07-platform-instance.png`: Köşe Mutfak şablon ve marka özelleştirme ekranı

Görüntüler gerçek parola, API anahtarı veya kişisel müşteri verisi içermez.

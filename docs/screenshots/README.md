# Ekran görüntüleri

Bu klasördeki 1440×900 görüntüler yerel demo verileriyle çalışan güncel uygulamadan alınmıştır:

- `01-home.png`: restoran ana sayfası
- `02-menu.png`: kategori, arama ve ürün kartları bulunan dijital menü
- `03-product.png`: responsive ürün detay ekranı
- `04-admin-dashboard.png`: oturum açılmış yönetici genel bakış ekranı
- `05-admin-products.png`: ürün arama, durum ve hızlı işlem ekranı

Görüntüler gerçek parola, API anahtarı veya kişisel müşteri verisi içermez.
